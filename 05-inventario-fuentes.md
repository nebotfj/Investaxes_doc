# Antes de importar: el inventario de fuentes

Este capítulo es el que más tiempo ahorra y el que casi todo el mundo se salta.

**Antes de conectar nada, escribe una lista completa de todas las plataformas que has usado alguna vez.** No las que usas ahora: **todas**, desde que empezaste a operar.

## Por qué es determinante

La cuenta que la gente olvida es casi siempre el exchange que usó durante tres meses y abandonó. Y casi siempre es justo el exchange donde compró las monedas que vendió después en otro sitio. Es decir: **la fuente olvidada suele contener el coste de adquisición de las ventas que sí declaras**.

El resultado de olvidarla es una venta sin compra localizada —una *venta vacía*— que el sistema resuelve asumiendo el peor escenario posible.

## Cómo reconstruir la lista

- **Correo electrónico.** Busca "verificación", "bienvenido", "confirma tu cuenta", "retirada". Los exchanges mandan correos de alta y de operaciones
- **Extractos bancarios.** Cualquier transferencia o cargo hacia una plataforma de cripto identifica una cuenta
- **Dispositivos antiguos.** Móviles y ordenadores viejos con apps o wallets instaladas
- **Gestores de contraseñas.** Las credenciales guardadas delatan cuentas olvidadas
- **Exploradores de blockchain.** Busca tus direcciones públicas y mira de dónde llegaron y hacia dónde salieron los fondos. Cada contraparte desconocida es una pista

## Qué anotar de cada fuente

| Dato | Para qué sirve |
|---|---|
| Nombre de la plataforma | Identificación |
| Tipo | Exchange centralizado / wallet autocustodiada / plataforma de inversión |
| Periodo de uso | Saber qué años cubrir al exportar |
| Estado | Activa / cerrada / inaccesible |
| Método de obtención de datos | Exportación de archivos / dirección pública / manual |

**Incluye también** las plataformas de preventas, las herramientas de inversión, las cuentas cerradas y cualquier sitio donde hayas tenido saldo aunque fuera brevemente.

## Orden de preferencia para obtener los datos

1. **Archivos exportados desde la plataforma** — método nativo para los exchanges soportados
2. **Dirección pública de blockchain** — para wallets autocustodiadas
3. **Plantilla de importación genérica** — para exchanges sin integración directa
4. **Entrada manual** — último recurso. Si tienes que hacerlo, **guarda capturas de pantalla como prueba**: si la AEAT pregunta, la captura es tu único respaldo
